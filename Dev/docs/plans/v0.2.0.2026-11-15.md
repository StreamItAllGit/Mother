## 5. Architecture & Technical Design

### 5.1 Installer Architecture (`T2` — `Mother.Installer`)
- `Mother.Installer.csproj#L13`: Set `<Company>StreamItAll</Company>` (fixing `Personal Suite`).
- `Mother.Installer\Program.cs` stays `< 140` SLOC as CLI parser, AssemblyResolve GZip loader, file-lock pre-wait, and entrypoint delegating into `Mother.Installer\MotherInstallerRunner.cs` (`<= 240` SLOC).
- `MotherInstallerRunner.BuildOptions(SandboxEnvironment sandbox, string version)` creates `InstallerThemeOptions` (`InstallerThemeOptions.cs#L56-123`) with `AppId = "mother"`, `DisplayName = "Mother"`, `Version = version`, `StudioName = "StreamItAll"`, `SuiteName = "Mother"`, `UmbrellaSubpath = @"StreamItAll\Mother\Mother"`, `DefaultInstallDir = ResolveMotherDefaultInstallDir(sandbox)`, `ExecutableFileName = "Mother.exe"`, `BrandAccentHex = "#38bdf8"`, `AllowAutoStart = true`, `DefaultProfileId = "full"`, `AvailableProfiles = [new("lightweight", InstallerProfileKind.Lightweight, ...), new("full", InstallerProfileKind.Full, ..., IsDefault: true)]`, `AllowLegacyMigration = true`, and `SecondaryPathPicker` (`--suite-dir`).
- `ResolveMotherDefaultInstallDir(sandbox)`:
  - When `sandbox.IsContainedSandbox`: strictly `Path.Combine(sandbox.DataDirectory, "installed-app")` (never touches `MOTHER_HOME` or HKCU!).
  - When non-sandbox: `MOTHER_HOME` -> `HKCU\Software\StreamItAll\Mother\SuiteInstallDir + "\Mother"` / `HKCU\Software\StreamItAll\Mother\InstallDir` -> `%LOCALAPPDATA%\Programs\StreamItAll\Mother\Mother`.
- Uses `InstallerEngineCore` + `InstallerWizardForm(coreEngine, customInstallAction: async (ct, progress) => ..., showShowcaseAutoCloseMs: 3000, ...)` (so GUI installs NEVER hit the empty-ZIP fallback at `InstallerWizardForm.ExecutionAndLogs.cs#L186-196`):
  - Both GUI `customInstallAction` and CLI silent path execute `coreEngine.InstallOrUpgradeFromZipAsync` on `Mother.Installer.Embedded.payload.zip`, copy `Mother-Uninstall.exe`, invoke `WindowsShortcutWriter` (shortcuts, Startup autostart when `AllowAutoStart && !NoStartup` and `!sandbox.IsContainedSandbox && !sandbox.DryRun`, HKCU Uninstall + `HKCU\Software\StreamItAll\Mother\{SuiteInstallDir,InstallDir,InstallProfile}` outside `--test-mode`/`--dry-run`), and run opt-in `DetectLegacyFlatInstall` / `MigrateLegacyInstallAsync` when `--migrate-legacy` or checkbox is selected (respecting `--dry-run`).
  - Under `--visible-test`, hooks `wizard.Shown` (before `_showcaseTimer` closes) to draw/capture the visible wizard surface to **strictly** `<logDir>\screenshots\installer-visible-test.png` (never inside `Installers\`).

### 5.2 Containment, Discovery & Supervision (`T3`, `T7`)
- **`PathResolver.cs`:**
  - `ResolveProgramsRoot`:
    1. If `explicitOverride` provided -> `AssertContainedIfSandbox(Path.GetFullPath(explicitOverride))`.
    2. `if (Sandbox.IsContainedSandbox)` -> **immediate return** `Path.Combine(DataDirectory, "mock-apps")`.
    3. `MOTHER_HOME` -> HKCU `Software\StreamItAll\Mother\SuiteInstallDir` -> `Directory.GetParent(BaseDirectory)` (`StreamItAll\Mother` if present) -> `%LOCALAPPDATA%\Programs\StreamItAll\Mother`.
  - `AssertContainedIfSandbox`: `string root = SandboxEnvironment.ResolveSiblingSandboxRoot(DataDirectory) ?? DataDirectory; return SandboxEnvironment.AssertPathContained(candidatePath, root);`.
- **`ManifestRegistryService.cs`:**
  - If `Sandbox.IsContainedSandbox`: scan **only** `_paths.ManifestsDirectory`, `_paths.ProgramsRoot` (`mock-apps`), and validated sandbox-contained `CustomManifestRoots` (NEVER HKCU or `<PROGRAMS_ROOT>/`!).
  - Otherwise: scan `_paths.ManifestsDirectory`, `_paths.ProgramsRoot` peers, HKCU `Software\StreamItAll\Mother\Apps\*` (`InstallDir`), `CustomManifestRoots`, and read-only fallback `<PROGRAMS_ROOT>/*`.
- **New Contracts & Helpers (`T7`):**
  - `SisterScheduleEntry` & `SisterCommandsEntry` in `FleetContracts.cs`: `Id`, `Name`, `Cadence`, `TimeUtc`, `RunIfMissed`, `TargetDrives`, `TriggerEndpoint`; `StartDaemon`, `Start`, `StopDaemon`, `StatusCheck`, `BackupNow`.
  - `WorkerLaunchCommandBuilder.cs`: validates `WorkingDirectory = paths.AssertContainedIfSandbox(entry.InstallDir)` (falling back to `Path.GetDirectoryName(exePath)`), prepends `entry.WorkerArgs` (or tokenized `entry.Commands?.StartDaemon ?? entry.Commands?.Start` if `WorkerArgs` empty and target is `.exe`/`.bat` args, resolving relative script via `cmd.exe /c` when `.bat`/`.cmd` or EXE + args cleanly), appends Mother flags (`--managed-by-mother --bind 127.0.0.1 --port <port> [--test-mode]`), and sets env `MANAGED_BY_SUITE=1`, `MOTHER_SUPERVISED=1`, `MOTHER_GATEWAY_URL=http://127.0.0.1:<motherPort>`.
  - `FleetScheduleEvaluator.cs`: loads/saves atomic `<dataDir>\scheduler-state.json` (`lastRunAtUtc`, `nextRunAtUtc`, `deferReason`), parses `cadence` (`hourly`/`daily`/`weekly`) + `timeUtc` (`HH:mm`), honors `runIfMissed` and `FleetCoexistenceArbitrator.ArbitrateColdWake`, wakes cold workers via `ColdWakeCoordinator.WakeAsync`, invokes `triggerEndpoint` when configured, and records `DeferSchedule(appId, scheduleId, deferMinutes, deferReason)` cleanly (used by `POST /api/v1/scheduler/defer`).
  - `ColdWakeCoordinator.EvaluateIdleHibernationAsync`: iterates managed `cold`/`on-demand` running children with `IdleTimeoutMinutes > 0`, skips active/busy (`ActiveJobs > 0 || QueuedJobs > 0`), and calls `_supervisor.StopAppAsync(appId)` once `DateTime.UtcNow - lastActivity >= idleTimeout`.
  - `ColdWakeProxyMiddleware.cs`: maps `/app/{appId}` -> `Results.Redirect($"/app/{appId}/", permanent: false)` (`307`), passes `X-Forwarded-Prefix: /app/{appId}` header on proxied `HttpRequestMessage`, and calls `TouchActivity(appId)` before/after response.
